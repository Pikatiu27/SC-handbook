# SC Handbook Pre-drawing Case Reviews

Store one project-owned review record here before creating a new controlled drawing family or materially changing an existing physical representation.

Use the current UWEDS `schemas/pre_drawing_case_review.schema.json`, `sources/PRE_DRAWING_CASE_REFERENCE_GUIDE.md` and `tests/PRE_DRAWING_CASE_REVIEW_CHECKLIST.md`. Record the engineering question, comparable cases, governing sources, differences, copying boundary, selected UWEDS modules and review ID.

Reference the review ID from `REFERENCE_TRACEABILITY.md` and from the drawing asset metadata where practical. A case review is supporting evidence; it does not replace project requirements, applicable Standards or current manufacturer documentation.
