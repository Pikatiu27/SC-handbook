How to use Find · filter · inspect

  1. Find a product

    Choose a component family, then search size, grade, supplier or part number. Accessories also has a type selector.

  2. Filter and sort

    Click a column name or its arrow. Search the checklist, select values, then choose Apply. Numeric columns also offer a range and sorting.

    Supplier and Construction / end form are under Model / size → Filter by.

  3. Inspect the record

    Select a model for its original rating, full dimensions and source notes. Close the record or press Escape to return to the same table position.

Refine your shortlist

Multiple values in one column include any selected value; different columns narrow the results together. Checklist search only narrows the options shown.

Nearby sizes finds the three closest recorded diameters within your filtered results. It does not establish fitting compatibility.

Clear or start again

Remove a filter tag, use Clear column in its menu, or choose Clear all above the table. Headers remain available when no products match.

Reset returns to Guy strand and clears search, nearby size, column filters and sorting. Close a filter menu or press Escape to cancel its uncommitted changes.

Read the catalogue values

Ratings: MBF/MBL = breaking force/load; WLL = working load limit; RHS = rated holding strength. MFL/tension rating retain manufacturer labels. Select one rating basis before numeric rating filtering or sorting. Ratings, proof loads and efficiency are not design resistance; kN is a unit conversion.

Gaps: — means missing, not zero. Conflicts are withheld; E/EA is not inferred. Drawing letters follow each supplier’s diagram.

Before use: check edition, region, supplied product and installation. AU listing is not owner approval; similar size is not verified fit or assembly capacity. Temporary grips are not permanent mast terminations.
